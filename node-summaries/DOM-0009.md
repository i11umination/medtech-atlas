# 物理学

## 一句话说明

研究能量、物质、波与场的规律，并把这些规律转化为成像、治疗和测量手段。

## 医学连接

本批内容重点连接声学聚焦、磁共振引导、粒子束输运与剂量沉积。物理模型既决定设备能否把能量送到目标，也决定正常组织会承受多少非目标暴露。

## 当前边界

更精确的能量分布不自动等于更好的患者结局；仍需临床试验比较症状、毒性、复发和生存等终点。
