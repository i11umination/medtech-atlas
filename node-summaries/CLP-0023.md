# PSMA 阳性 mCRPC 的靶向放射递送与累积毒性

## 一句话说明

如何把电离辐射更多递送到 PSMA 表达转移灶，同时控制骨髓、肾脏和其他正常组织的累积暴露。

## 医学连接

治疗链同时依赖配体化学、核素标记、PSMA PET 选择、剂量学、放射防护和血液学监测。
