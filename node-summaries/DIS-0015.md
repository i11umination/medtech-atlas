# 结直肠癌

## 一句话说明

发生于结肠或直肠的恶性肿瘤，术后辅助治疗取决于分期、病理风险和分子特征。

## 本库关注点

II 期结肠癌 DYNAMIC 试验检验了术后 ctDNA 指导辅助化疗的策略，显示可减少化疗使用且无复发生存不劣于常规指导。

## 边界

该结果不代表所有结直肠癌分期、直肠癌治疗路径或所有 ctDNA 平台均可照搬。
