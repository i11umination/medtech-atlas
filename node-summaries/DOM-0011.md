# 遗传学、基因组学与生物信息学

## 一句话说明

研究遗传信息的变异、表达与调控，并用计算方法识别与疾病和治疗相关的分子信号。

## 医学连接

本批内容连接 ctDNA 变异与甲基化分析、CRISPR 靶点设计和工程细胞产品的分子质量控制。

## 当前边界

检测到分子信号不等于该信号可直接指导治疗；基因编辑也必须分别核验脱靶、克隆演化、递送和长期安全问题。
