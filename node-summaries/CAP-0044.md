# 长效肽类受体激动剂设计与剂量递增

## 一句话说明

通过延长肽类受体激动剂作用时间和逐步增加剂量，实现每周给药并改善耐受性。

## 医学连接

司美格鲁肽 2.4 mg 用这项药理与制剂能力影响食欲和体重，并在 SELECT 中接受心血管结局检验。

## 当前证据边界

代谢机制或体重下降不能自动证明心血管事件获益；不良反应停药、禁忌和产品剂量差异需独立处理。

## 仍待回答的问题

怎样识别绝对获益较高且能长期耐受治疗的人群。
