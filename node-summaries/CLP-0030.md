# 非糖尿病超重或肥胖人群的主要心血管事件降低与停药负担

## 一句话说明

如何在无糖尿病的超重或肥胖心血管病患者中减少再次发生心梗、卒中或心血管死亡。

## 医学连接

SELECT 使用临床事件而非仅体重或代谢替代指标检验司美格鲁肽 2.4 mg 的二级预防价值。

## 当前证据边界

MACE 相对风险下降伴随较高不良反应停药；心衰结果来自同一队列的预设亚组。

## 仍待回答的问题

需要理解长期持续用药、停止治疗后的风险、成本可及性和不同基础风险的绝对获益。
