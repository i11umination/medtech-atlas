# 镰状细胞病

## 一句话说明

由血红蛋白异常引起的遗传性疾病，可导致溶血、血管阻塞危象和多器官损伤。

## 本库关注点

CASGEVY 通过体外 CRISPR 编辑自体造血干细胞提高胎儿血红蛋白，已获 FDA 批准用于符合标签条件的患者。

## 边界

治疗涉及清髓和移植流程，短期危象改善不能替代长期克隆安全、器官结局、生育影响和可及性评估。
