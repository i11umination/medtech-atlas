# 基因编辑造血重建的持久性与长期安全

## 临床问题

一次体外编辑和造血重建能否长期消除严重症状，同时把脱靶、克隆、清髓和移植相关风险控制在可接受范围？

## 当前证据

CASGEVY 已获 FDA 批准；镰状细胞病和输血依赖型 β 地中海贫血的单组 III 期研究显示强疗效信号，但长期和比较性证据仍在积累。

## 判断边界

需同时评价编辑产品、预处理、支持治疗、长期随访与可及性，不把“基因编辑”视为单一操作。
