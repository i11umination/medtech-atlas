# B 细胞前体 ALL 巩固治疗的复发控制与免疫毒性

## 一句话说明

如何在巩固期更彻底清除残留白血病并降低复发，同时避免进一步强化化疗和免疫毒性。

## 医学连接

blinatumomab 以 CD19/CD3 接合替代或加入部分化疗，试验使用 OS、DFS、MRD 和严重感染评价净获益。

## 当前证据边界

不同试验结论并非完全一致；提前停止、次要终点和不同风险分层都要求逐项解释。

## 仍待回答的问题

未来需要明确不同 MRD 水平、年龄和复发类型中的最优周期与移植衔接。
