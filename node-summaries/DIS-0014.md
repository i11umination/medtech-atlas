# 帕金森病

## 一句话说明

以运动迟缓为核心，并可伴震颤、肌强直、姿势步态和多种非运动症状的进行性神经系统疾病。

## 本库关注点

聚焦超声可针对某些症状和靶点开展消融，但本批完整证据包主要针对特发性震颤；帕金森病不应由特发性震颤结果直接外推。

## 边界

不同症状、分期、药物反应和认知状态会改变治疗选择，程序性治疗也不等同于阻止疾病进展。
