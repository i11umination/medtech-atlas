# 非小细胞肺癌

## 一句话说明

占肺癌多数的一组恶性肿瘤，其治疗需结合分期、组织学、分子分型和患者状态。

## 本库关注点

本批从两条路径切入：ctDNA 甲基化在检测和监测中的证据缺口，以及质子相对光子放疗能否改善毒性和肿瘤控制。

## 边界

分子检测用途之间不可混同；质子剂量学优势也不能替代临床结局证据。
