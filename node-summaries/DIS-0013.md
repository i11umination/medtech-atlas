# 特发性震颤

## 一句话说明

以动作性和姿势性震颤为主要表现的常见运动障碍，可显著影响书写、进食和日常活动。

## 本库关注点

当药物控制不足且功能受损明显时，MRgFUS 丘脑切开是特定患者可讨论的程序性治疗之一；本批证据覆盖随机假手术对照、五年随访和系统综述。

## 边界

诊断、严重度、优势手和双侧症状会影响选择；“无切口”不等于无不良事件，也不保证症状永久不变。
