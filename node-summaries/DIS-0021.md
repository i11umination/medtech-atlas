# 食管癌

## 一句话说明

发生于食管的恶性肿瘤，局部晚期治疗常需综合放疗、化疗和手术策略。

## 本库关注点

随机 IIb 期研究比较质子与调强光子放疗，观察到质子组较低的一年总毒性负担，而三年无进展生存和总生存相近。

## 边界

样本量、复合终点和旧一代质子技术限制外推，不能据此宣称所有食管癌患者均应选择质子。
