# 每周一次司美格鲁肽 2.4 mg（Wegovy）

## 一句话说明

一种每周皮下注射的 GLP-1 受体激动剂剂量方案，在生活方式干预基础上用于特定肥胖相关风险。

## 医学连接

SELECT 在无糖尿病且已有心血管疾病的超重或肥胖成人中显示 MACE 从 8.0% 降至 6.5%。

## 当前证据边界

试验人群属于二级预防，因不良事件永久停药明显更多；同一试验的心衰亚组不是独立重复验证。

## 仍待回答的问题

长期停药、体重反弹、绝对风险差异和不同共病人群的净获益仍需跟踪。
