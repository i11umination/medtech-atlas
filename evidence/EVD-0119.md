# FDA 批准 Wegovy 降低既有心血管疾病成人的严重心血管事件风险

## 研究问题

FDA 将 Wegovy 的心血管风险降低适应证限定于已有心血管疾病且超重或肥胖的成人，并要求配合饮食与体力活动。

## 研究设计与对象

监管批准与关键结局试验汇总；对象为已有心血管疾病且超重或肥胖的成人；样本量：批准依据的 SELECT 试验超过 17600 人。

## 干预与比较

- 干预：每周司美格鲁肽 2.4 mg 加生活方式干预
- 比较：安慰剂加生活方式干预

## 主要结果

FDA 页面报告主要心血管事件发生于 6.5% 对 8.0%，据此批准相应风险降低适应证。

## 局限与谨慎解释

批准范围是已有心血管疾病的成人二级预防，不代表所有肥胖人群；药物禁忌、不良反应和停药问题需参照现行说明书。
