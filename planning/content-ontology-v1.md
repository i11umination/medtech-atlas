# 内容与本体规范 v1

状态：已获用户批准，作为大型内容库建设前的导航与内容组织基线。  
确定日期：2026-09-12

数据模型补充：核心能力作为正式 `capability` 节点纳入图谱，使用 `CAP-*` 稳定 ID；Schema 版本升级为 1.1.0。

## 1. 核心原则

网站从科学门类和疾病/健康状态问题两个方向进入同一张知识图谱，但最终都要连接到可核验的研究证据和患者相关结局。

推荐路径为：

> 科学门类 → 核心能力 → 技术 → 临床问题 → 疾病/健康状态 → 研究证据 → 患者结局

图谱是知识导航工具，不是底层数据库的全量镜像。上层展示聚合结构，下层逐步展开实体、关系和证据。

## 2. 五层导航结构

| 层级 | 展示内容 | 默认呈现 |
| --- | --- | --- |
| 第 0 层 | 科学与技术体系、疾病与临床问题、研究与证据 | 三个总体入口 |
| 第 1 层 | 工程与信息科学、基础科学、生命与认知科学、交叉科学方向，以及疾病系统 | 聚合分组与内容数量 |
| 第 2 层 | 具体科学门类、疾病与健康状态、临床问题和技术 | 不超过约 20 个成员节点 |
| 第 3 层 | 选定实体周围一至两跳的主题子图 | 最多 40 个节点，研究节点默认折叠 |
| 第 4 层 | 单条技术—医学关系及其研究、证据卡和来源 | 线性证据链 |

层级表示导航深度，不表示科学价值高低或研究成熟度。

## 3. 科学门类分组

### 工程与信息科学

- 机械工程；
- 电子与信息工程；
- 材料科学与工程；
- 计算机科学与人工智能；
- 自动化与控制科学；

机器人学归入机械工程，作为感知、机构、执行、控制与人机协同的综合应用方向，不再单列平行门类。

当前“自动化”在扩展时升级为“自动化与控制科学”，暂不把控制科学拆成重复入口。

2026-09-13 结构修订：旧 `DOM-0003` 已完整归并到 `DOM-0001`，机器人相关技术通过“生物力学与人机耦合”和“精密机构与器械执行”两个核心能力进入图谱；旧地址保留永久重定向。

### 基础科学

- 物理学；
- 化学与化学工程；
- 数学与统计学。

2026-09-13 结构修订：化学与化学工程合并为基础科学门类 `DOM-0015`；旧化学工程节点 `DOM-0016` 停用并永久重定向到合并节点。

### 生命与认知科学

- 神经科学与认知科学；
- 分子与细胞生物学；
- 遗传学、基因组学与生物信息学；
- 免疫学；
- 药理学与药剂学。

### 交叉科学方向

- 纳米科学；
- 再生医学与组织工程；
- 合成生物学。

交叉方向不是传统门类的唯一上级，可与多个科学门类建立跨学科关系。

## 4. 主要导航归属与跨学科关系

每个实体设置一个主要导航归属，用于决定默认下钻路径和面包屑；同时允许出现在其他分组的 `cross_node_ids` 中。

例如脑机接口可主要归入电子与信息工程，同时连接神经科学、计算机科学与人工智能、自动化与控制科学。主要归属只是导航选择，不代表学术排他性。

跨学科节点在界面中应显示“还可从其他门类进入”，不能复制为多个互不相连的实体。

底层 `disease` 类型用于承载“疾病与健康状态”，既可表示明确疾病，也可表示截肢、先天性肢体缺失等不宜强行归为单一疾病的状态；前台统一显示“疾病与健康状态”。

## 5. 图谱交互规则

- 使用“全局框架—主题探索—证据链”三种视图；
- 点击负责进入下一层，滚轮只调整当前层的观察范围；
- 上层节点不显示全部底层连线，只显示聚合数量；
- 第 3 层默认显示一至两跳关系，节点上限为 40；
- 研究节点在主题图中默认折叠，在证据链视图中展开；
- 搜索结果可以直接打开对应主题层；
- 每层状态写入 URL，刷新和分享后仍可恢复；
- 面包屑与返回路径负责回到上层，不依赖浏览器历史。

## 6. 新门类发布门槛

批准进入扩展规划，不等于立即作为正式医学内容发布。一个新门类至少满足以下条件后，才生成正式实体页：

1. 有通俗简介和至少一个可核验的门类定义来源；
2. 至少连接两个具体技术或核心能力；
3. 至少形成一条“技术—临床问题—研究证据”完整路径；
4. 标明研究阶段、适用范围、局限和最近核验时间；
5. 通过数据校验与医学安全初审。

## 7. 双轨扩展顺序

### 第一批

电子与信息工程、材料科学与工程、计算机科学与人工智能、神经科学与认知科学、自动化与控制科学。优先连接脑卒中、脑动脉瘤、神经介入、康复机器人、智能假肢和脊柱手术。

### 第二批

原计划为物理学、数学与统计学、化学与化学工程。因物理学、数学与统计学已在 6+3 扩展中提前完成，实际第二批集中建设合并后的化学与化学工程，并同步清零纳米科学、再生医学与组织工程、合成生物学三个交叉门类的空白。重点以已获监管批准的代表技术建立完整证据路径。

### 第三批

采用 A 路线，在已纳入门类中纵向增加独立临床路径，并同步维护现有来源。第一波聚焦化学与化学工程、纳米科学、再生医学与组织工程、合成生物学；不针对脑卒中、肿瘤或其他疾病类型设置比例目标或默认优先级。新型递送、工程细胞和组织修复按实际证据阶段建设。

每批同时建设数据规范、内容入库流程和约 30—50 张高质量证据卡，用真实内容检验本体，而不是先建立大量空节点。
