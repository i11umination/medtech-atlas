## 1. 已确认范围

第二波同时纳入五条监管或临床证据相对成熟的路径，以及两条前沿早期人体路径：

1. 自动胰岛素递送；
2. blinatumomab 双特异 T 细胞衔接治疗；
3. HEMGENIX AAV5 体内基因治疗；
4. semaglutide 2.4 mg 心血管风险降低；
5. 导管肾去神经；
6. SYNB1891 工程细菌；
7. zimislecel 干细胞来源胰岛细胞治疗。

第一波已经完成 4 条路径、12 张证据卡。第二波实际形成 7 条路径、26 张证据卡，第三阶段累计 11 条路径、38 张证据卡，处于已确认的“8—12 条路径、30—50 张证据卡”规划范围内。

以上数量只用于工作包估算，不是纳入配额。若原始来源不足、同队列重复、监管边界不清或无法合法核验，应减少证据卡或延期整包，不得拆分同一结果凑数。

选题仍不针对脑卒中、肿瘤、糖尿病或其他疾病设置数量、比例或优先级。两条 1 型糖尿病路径同时出现，是因为它们能形成“器械闭环控制”和“细胞替代”之间的结构对照，而不是疾病配额。

## 3. 各包证据结构与边界

### 3.1 自动胰岛素递送

候选来源：

- [FDA K232382：Control-IQ 扩展至 2 岁及以上 1 型糖尿病人群](https://www.accessdata.fda.gov/cdrh_docs/pdf23/K232382.pdf)
- [FDA K243823：Control-IQ+ 当前用途包含成人 2 型糖尿病](https://www.accessdata.fda.gov/cdrh_docs/pdf24/K243823.pdf)
- [六个月多中心随机试验，PMID 31618560](https://pubmed.ncbi.nlm.nih.gov/31618560/)

必须保留：

- 第二波临床路径限定为 1 型糖尿病，不把 1 型糖尿病随机试验外推到 2 型糖尿病；
- 目标范围内时间、HbA1c 和低血糖时间属于血糖管理结局，不等同于已经证明减少长期微血管、心血管事件或死亡；
- 设备仍依赖兼容的持续葡萄糖监测、泵、耗材、使用者操作和异常处置，不得称为完全自主系统；
- 必须记录酮症酸中毒、输注中断、传感器或算法失效等风险。

### 3.2 blinatumomab

候选来源：

- [FDA：2024 年巩固治疗适应证](https://www.fda.gov/drugs/resources-information-approved-drugs/fda-approves-blinatumomab-consolidation-cd19-positive-philadelphia-chromosome-negative-b-cell)
- [E1910 成人随机试验，PMID 39047240](https://pubmed.ncbi.nlm.nih.gov/39047240/)
- [AALL1331 高/中危首次复发随机试验，PMID 33651090](https://pubmed.ncbi.nlm.nih.gov/33651090/)
- [20120215 儿童高危首次复发随机试验，PMID 33651091](https://pubmed.ncbi.nlm.nih.gov/33651091/)
- [AALL1331 低危首次复发分析，PMID 37257143](https://pubmed.ncbi.nlm.nih.gov/37257143/)

必须保留：

- 成人初治 MRD 阴性缓解、儿童首次复发及不同风险层不能合并成单一疗效结论；
- AALL1331 低危总体 DFS/OS 未达统计学显著，骨髓复发亚组信号不能替代总体结果；
- 持续输注、细胞因子释放综合征、神经毒性、感染和治疗方案差异必须进入证据卡；
- FDA 对三个随机研究的综合判断与每项原始研究分别记录，不重复计算为独立试验。

### 3.3 HEMGENIX

候选来源：

- [FDA HEMGENIX 产品页与当前标签](https://www.fda.gov/vaccines-blood-biologics/vaccines/hemgenix)
- [HOPE-B 18 个月主要分析，PMID 36812434](https://pubmed.ncbi.nlm.nih.gov/36812434/)
- [HOPE-B 24 个月分析，PMID 38437857](https://pubmed.ncbi.nlm.nih.gov/38437857/)
- [HOPE-B 最终分析，PMID 41358585](https://pubmed.ncbi.nlm.nih.gov/41358585/)

必须保留：

- HOPE-B 是 54 名成人男性的开放标签单臂研究，以治疗前导入期作自身比较；
- 18 个月、24 个月和最终分析来自同一队列，只表示随访延长，不表示独立重复验证；
- 适用人群、FIX 抑制物、AAV5 中和抗体、肝脏筛查、转氨酶升高、糖皮质激素使用和长期随访要求必须保留；
- 不把减少凝血因子预防用量改写为永久治愈。

### 3.4 semaglutide 2.4 mg 与 SELECT

候选来源：

- [FDA：Wegovy 心血管风险降低适应证](https://www.fda.gov/news-events/press-announcements/fda-approves-first-treatment-reduce-risk-serious-heart-problems-specifically-adults-obesity-or)
- [SELECT 主要随机结果，PMID 37952131](https://pubmed.ncbi.nlm.nih.gov/37952131/)
- [SELECT 心力衰竭预设分析，PMID 39181597](https://pubmed.ncbi.nlm.nih.gov/39181597/)

必须保留：

- 适用范围限定为已有心血管疾病且超重或肥胖、没有糖尿病的 SELECT 人群，不能泛化为所有超重或肥胖者；
- MACE 相对风险降低与绝对事件率同时呈现；
- 主要试验中因不良事件永久停药比例高于安慰剂，安全性和停药负担不能省略；
- 心衰及其他亚组分析来自 SELECT 同一队列，需标明预设或探索性质。

### 3.5 导管肾去神经

候选来源：

- [FDA Paradise 超声肾去神经系统，P220023](https://www.fda.gov/medical-devices/recently-approved-devices/paradise-ultrasound-renal-denervation-system-p220023)
- [FDA Symplicity Spyral 射频肾去神经系统，P220026](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfpma/pma.cfm?id=P220026)
- [RADIANCE II 假手术对照随机试验，PMID 36853250](https://pubmed.ncbi.nlm.nih.gov/36853250/)
- [RADIANCE-HTN TRIO 假手术对照随机试验，PMID 34010611](https://pubmed.ncbi.nlm.nih.gov/34010611/)
- [SPYRAL HTN-ON MED 24 个月结果，PMID 40391448](https://pubmed.ncbi.nlm.nih.gov/40391448/)

必须保留：

- 超声与射频系统具有不同装置、试验和适用条件，只在通用技术层聚合，不互相替代；
- 关键试验主要证明血压降低，不能写成已经证明减少心肌梗死、卒中、肾衰竭或死亡；
- SPYRAL HTN-ON MED 六个月 24 小时动态收缩压结果与办公室血压结果不一致；长期分析还受解盲、交叉和缺失数据影响；
- 入库时必须重新检查 PMA 最新补充文件，不能只使用 2023 年初始标签。

### 3.6 SYNB1891

候选来源：

- [SYNB1891 临床前机制研究，PMID 32483165](https://pubmed.ncbi.nlm.nih.gov/32483165/)
- [首个人体 I 期研究，PMID 37227176](https://pubmed.ncbi.nlm.nih.gov/37227176/)
- [ClinicalTrials.gov NCT04167137](https://clinicaltrials.gov/study/NCT04167137)

必须保留：

- 研究共 32 人，其中 24 人单药、8 人联合 atezolizumab，主要目标是安全性、耐受性和靶点结合；
- 4 人稳定疾病不能解释为已证明抗肿瘤疗效；
- 细胞因子释放综合征、最高剂量的剂量限制性毒性、肿瘤内注射方式和企业参与必须披露；
- 注册记录显示研究因商业原因提前终止。该路径是历史早期人体证据，不得显示为正在招募、持续开发或已获批准疗法。

### 3.7 zimislecel

候选来源：

- [早期人体研究，PMID 40544428](https://pubmed.ncbi.nlm.nih.gov/40544428/)
- [ClinicalTrials.gov NCT04786262](https://clinicaltrials.gov/study/NCT04786262)

必须保留：

- 已发表结果为开放标签、单组、I—II 期研究的 14 人中期分析，分析并非预先设定；
- 所有参与者接受免疫抑制，不能把细胞植入效果与免疫抑制风险分离；
- 门静脉输注、移植物功能、严重低血糖、HbA1c 和胰岛素独立分别记录；
- 当前属于研究性疗法，不得显示为获批治疗、标准治疗或已确定的长期治愈路径。

## 4. 实现方式 A

第二波正式实施使用一个 `scripts/ingest-third-stage-wave-2.mjs` 幂等脚本，复用第一波既有模式，没有引入新的入库框架。

脚本要求：

- 七个证据包按独立数据块组织，但一次运行统一执行；
- 对节点、关系、来源、证据索引、通俗医学连接和导航归属进行稳定 ID 的 upsert；
- 重复运行不得增加重复节点、关系或来源；
- 任一包未通过来源锁定时，不把该包写入公开数据；
- 脚本不配置数据库、Cloudflare D1、Pages Binding、审核后台或部署；
- 对外推送、发布和修改托管配置继续需要用户单独确认。

## 5. 执行关卡

### 关卡 A：来源锁定

- 重新打开并逐条核对所有候选来源；
- 确认当前监管标签、研究身份、对象、比较、终点、结果、限制、资助和利益冲突；
- 把同一队列的主要、延长、亚组和最终分析建立关联；
- 将撤稿、无法核验或已改变身份的来源排除或降级。

### 关卡 B：证据提取

- 成熟路径至少包含当前监管边界和一项原始临床研究；
- 前沿路径必须同时显示注册状态和实际研究阶段；
- 监管文件、注册记录、临床前研究和人体研究分别承担不同证据职责；
- 事实、项目解释和未来推断分开保存。

### 关卡 C：图谱策展

- 优先复用“实时反馈与自适应控制”及“细胞分化、成熟与移植物整合”等现有能力；
- 新能力必须可复用，不以产品名充当能力；
- 每个新实体只有一个主导航归属，跨学科联系使用关系表达；
- 七条路径均须贯通门类、能力、技术、临床问题、疾病或健康状态与证据，禁止孤立节点和越层直连。

### 关卡 D：验收

- 所有公开证据卡为 `review_status: source-checked`；
- `expert_review_status: not-performed` 仅作透明披露，不生成待审任务；
- 所有新页面显示研究阶段、阴性或不一致结果、安全性、同队列关系和外推限制；
- `npm run validate:data`、`npm run audit:coverage`、`npm run audit:professional`、`npx tsc --noEmit` 和 `npm run build` 全部通过；
- 人工抽查七条代表实体页、七条应用关系页和全部新增证据页；
- 第二波完成后再评估静态页面数量、首页图谱加载和交互性能，不因预估增长提前迁移数据库或图数据库。

## 6. 同步维护范围

维护采用风险触发而非固定数量。第二波至少复核：

- 与新路径发生交叉关系的现有基因、细胞、免疫、药理和物理学来源；
- 可能出现新适应证、黑框警告、安全通信或 PMA 补充的监管来源；
- 第一波四条路径的当前产品页和标签是否仍与既有证据卡一致；
- 同一研究队列被多张证据卡使用时，页面是否明确显示重复来源关系。

## 7. 明确不做

- 不按疾病设置配额、占比目标或默认优先级；
- 不把监管批准、临床试验、早期人体、临床前和理论研究混为同一证据等级；
- 不设置独立医学专家审校关卡，也不把专家审校写入后续待办；
- 不接通用户需求系统，不配置 D1、Binding、审核后台或相关部署；
- 不推送远程仓库，不触发 GitHub Pages 发布。
