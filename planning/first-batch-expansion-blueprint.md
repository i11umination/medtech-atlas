# 大型内容库第一批扩展蓝图

状态：流程方案已获确认；本内容蓝图待逐条审核  
拟定日期：2026-09-12

## 1. 本批次已确认的执行约束

- 扩展五个科学门类：电子与信息工程、材料科学与工程、计算机科学与人工智能、神经科学与认知科学、自动化与控制科学；
- 核心能力作为正式 `capability` 节点，使用 `CAP-*` 稳定 ID；
- 来源发现采用 A+B：人工精选作为最终纳入标准，开放元数据/API 作为主要发现和元数据整理入口；
- 自动化发现不等于自动入库，任何医学事实仍需来源核验和医学审核；
- 每个新门类建议至少形成两条完整路径；
- 本批次目标约 30—50 张证据卡，但不为填满数量而纳入证据不足的关系；
- 新增内容先进入待审核工作区，不直接进入公开发布状态。

## 2. 路径结构

每条正式路径统一使用：

> 科学门类 → 核心能力 → 技术 → 临床问题 → 疾病 → 研究证据 → 患者结局

“核心能力”是可复用的一等节点。一个能力可以连接多个科学门类和技术，但不应因为跨学科出现而复制成多个实体。

## 3. 五个科学门类的候选路径

### 3.1 电子与信息工程

候选核心能力：信号采集与感知、实时数据传输与嵌入式集成、医学影像与多模态数据采集。

| 候选路径 | 优先技术 | 医学连接 | 预计难度 |
| --- | --- | --- | --- |
| 信号采集与感知 → 可穿戴运动/肌电/脑电监测 → 脑卒中后运动功能障碍 | 可穿戴传感器、EMG/EEG/IMU | 运动评估、训练反馈、患者分层 | 中 |
| 医学影像采集与导航 → 影像引导介入 → 脑动脉瘤/神经血管介入 | 多模态影像、导航系统 | 定位、路径规划、操作辅助 | 中高 |
| 人机接口与数据采集 → 神经接口/脑机接口 → 肢体功能重建 | 神经接口、运动意图采集 | 意图识别、感觉反馈、功能动作 | 高 |

预计规模：新增或完善 2—3 个核心能力、4—6 条技术关系、6—9 张证据卡。

建议检索词：

- `EEG EMG IMU stroke rehabilitation brain computer interface clinical study`
- `wearable sensor post-stroke motor assessment validation`
- `image-guided robotic neurovascular intervention navigation clinical study`

### 3.2 材料科学与工程

候选核心能力：生物相容界面、柔性与皮肤接触材料、植入器械材料与长期稳定性。

| 候选路径 | 优先技术 | 医学连接 | 预计难度 |
| --- | --- | --- | --- |
| 生物界面材料 → 神经电极/感觉接口 → 截肢后的感觉反馈 | 植入式电极、封装和界面材料 | 信号稳定、组织反应、长期使用 | 高 |
| 柔性与皮肤接触材料 → 假肢接受腔/接触界面 → 肢体缺失后的舒适性与皮肤安全 | 柔性材料、压力分布与皮肤保护 | 舒适性、皮肤损伤、日常可用性 | 高 |
| 植入器械材料 → 弹簧圈/支架等血管内器械 → 脑动脉瘤介入 | 血管内植入材料 | 可释放性、稳定性、并发症风险 | 中高 |

预计规模：新增或完善 2—3 个核心能力、3—5 条技术关系、4—7 张证据卡。

建议检索词：

- `neural interface electrode biocompatibility sensory prosthesis human study`
- `prosthetic socket soft material amputee skin comfort clinical outcome`
- `cerebral aneurysm stent coil biomaterial clinical study long-term outcome`

材料科学内容必须特别区分材料性能、器械性能和患者结局，不能由体外强度、导电性或耐久性直接推导临床获益。

### 3.3 计算机科学与人工智能

候选核心能力：医学影像分析、模式识别与预测、意图识别与自适应决策、手术规划与导航计算。

| 候选路径 | 优先技术 | 医学连接 | 预计难度 |
| --- | --- | --- | --- |
| 医学影像分析 → 卒中/动脉瘤影像 AI → 急性脑卒中识别与分层 | 检测、分割、风险分层模型 | 影像识别、分诊、患者分层 | 中高 |
| 意图识别 → 肌电/脑电控制 → 智能假肢或外骨骼 | 机器学习解码、自适应控制接口 | 功能动作和训练个体化 | 高 |
| 规划与导航计算 → 脊柱/神经血管手术辅助系统 → 精准定位与操作 | 术前规划、路径规划、导航 | 技术精度、辐射、手术流程 | 中高 |
| 功能评估 → 自动化运动分析 → 卒中或脊髓损伤康复评估 | 姿态估计、动作识别、数字终点 | 客观评估和长期随访 | 中高 |

预计规模：新增或完善 3—4 个核心能力、5—8 条技术关系、8—12 张证据卡。

建议检索词：

- `stroke imaging AI triage prospective external validation`
- `cerebral aneurysm imaging artificial intelligence external validation`
- `EMG intent recognition prosthesis amputee clinical study daily use`
- `AI surgical planning robotic spine navigation clinical outcome`

AI 内容必须额外记录训练数据、外部验证、数据漂移、公平性、可解释性和临床工作流位置。

### 3.4 神经科学与认知科学

候选核心能力：神经可塑性与运动学习、神经活动解码、感觉整合与身体表征。

| 候选路径 | 优先技术 | 医学连接 | 预计难度 |
| --- | --- | --- | --- |
| 神经可塑性与运动学习 → 机器人辅助训练 → 脑卒中后运动功能障碍 | 康复机器人、训练剂量和反馈 | 运动恢复、训练分层 | 中高 |
| 神经活动解码 → 脑机接口/神经接口 → 卒中或肢体缺失后的功能重建 | BCI、神经信号解码 | 运动意图、辅助动作 | 高 |
| 感觉整合与身体表征 → 感觉反馈假肢 → 肢体缺失后的具身感和功能使用 | 触觉反馈、感觉替代 | 真实生活使用和心理社会体验 | 高 |

预计规模：新增或完善 2—3 个核心能力、4—6 条技术关系、6—9 张证据卡。

建议检索词：

- `neuroplasticity motor learning robot-assisted stroke rehabilitation biomarker`
- `brain computer interface stroke upper limb rehabilitation human trial`
- `sensory feedback prosthesis embodiment everyday use human study`

需要避免把神经机制相关性直接写成某种训练或设备对患者有效。

### 3.5 自动化与控制科学

候选核心能力：闭环运动控制、实时反馈与自适应控制、精准轨迹执行、实验流程自动化。

| 候选路径 | 优先技术 | 医学连接 | 预计难度 |
| --- | --- | --- | --- |
| 闭环运动控制 → 自适应康复机器人 → 脑卒中/脊髓损伤康复 | 机器人训练、按需辅助 | 训练剂量、个体化和安全 | 中高 |
| 实时反馈与自适应控制 → 智能假肢/外骨骼 → 肢体功能重建 | 多传感器控制、意图识别 | 稳定性、可靠性、日常使用 | 高 |
| 精准轨迹执行 → 手术机器人/介入机器人 → 脊柱手术或神经血管介入 | 导航、执行和转换机制 | 技术成功、流程、安全和患者结局 | 中高 |
| 实验流程自动化 → 类器官筛选与自动图像分析 → 医学研究与转化平台 | 高通量平台、自动化分析 | 重复性、通量和转化验证 | 中 |

预计规模：新增或完善 3—4 个核心能力、5—8 条技术关系、7—10 张证据卡。

建议检索词：

- `adaptive control rehabilitation robot stroke spinal cord injury clinical trial`
- `closed-loop prosthesis control amputee daily use clinical study`
- `robotic neurovascular intervention navigation clinical outcome`
- `laboratory automation organoid screening reproducibility translational validation`

实验室自动化作为平台技术支线保留。体外类器官结果可以证明平台能力，但不能单独作为患者获益路径或临床疗效证据。

## 4. 批次级规模预估

| 内容类型 | 预估新增量 |
| --- | ---: |
| 正式科学门类节点 | 5 |
| 核心能力节点 | 约 8—12，跨门类复用 |

以上是工作量估计，不是必须填满的配额。医学证据不足时，保留为规划项或待研究问题。

## 5. 进入正式实体页的门槛

每个新科学门类和核心能力至少需要：

1. 通俗简介和可核验定义来源；
2. 至少两个具体技术或下游能力连接；
3. 至少一条“技术—临床问题—研究证据”完整路径；
4. 研究阶段、适用范围、局限和最近核验日期；
5. 数据校验和医学安全初审通过；
6. 具备相应的 Markdown 内容，不生成空白公开页面。

第一批推荐标准提高为：每个新科学门类至少两条完整路径，再进入正式发布候选区。
