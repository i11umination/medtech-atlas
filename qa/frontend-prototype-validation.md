# Astro 前端原型验证报告

验证日期：2026-09-12

## 实现范围

- 首页：自然语言输入、本地规则归纳、可折叠阅读偏好、简化知识图谱、六个示范主题；
- 图谱探索页：全局框架、分组下钻、主题子图和关系证据链五层导航；保留全局/与我相关范围、节点类型筛选、缩放拖动和详情侧栏；
- 实体详情页：按 41 个节点静态生成，显示通俗简介、可靠来源、相邻关系、研究阶段、限制和证据入口；
- 证据详情页：按 18 张证据卡静态生成，显示研究设计、样本、干预与对照、结果、局限和来源；
- 方法与声明页：证据阶段、关系边界、未来方向标记规则和医学免责声明。

## 面包屑与返回路径

- 实体、关系、证据卡和未来研究方向四类详情页均显示 `aria-label="面包屑导航"` 的层级导航；
- 面包屑使用数据关系生成稳定层级，不依赖浏览器访问历史；
- 四类详情页均显示 `aria-label="返回路径"` 的语境化入口；
- 返回图谱的链接携带 `focus` 参数，可重新聚焦对应节点；
- 证据卡和未来研究方向可返回其第一条直接关系，同时保留其他关联内容入口；
- 移动端下，面包屑允许换行，返回按钮组纵向排列，避免长标题挤压页面。

## 研究者继续阅读

- 实体页、关联页和证据卡均包含“研究者继续阅读”模块；
- 模块从现有证据与来源数据自动汇总研究类型、研究阶段、样本量、可信度、已提取结局、主要发现和外推边界；
- 原始来源区域显示来源类型、年份、DOI、注册号和合法外链；
- 证据链入口连接实体、关联详情或图谱焦点；
- 尚未结构化提取的资助和利益冲突信息明确提示读者查阅论文原文，没有自动推断；
- 没有直接证据的实体显示透明空状态，不把“缺少证据”解释为有效或无效。

## 数据驱动可视化

- 实体页根据直接相邻节点生成可点击的关系轨道图，并显示关联节点、证据数量、最新来源年份和最高研究阶段；
- 关联页将来源、机制、目标、证据阶段和患者相关结局组织为五步医学进展路径；
- 证据卡以 PICO 结构显示研究对象、干预、对照和结局，并用成熟度尺区分体外、动物、早期人体、临床试验和监管批准；
- 研究者继续阅读模块按来源年份自动生成证据时间线；
- 所有图形均来自现有结构化数据，不把阶段、样本量或证据数量转换成虚构的疗效百分比；
- 移动端的关系路径与 PICO 图改为纵向排列，轨道图、成熟度尺和时间线允许横向滚动。

## 分层图谱与首页徽标

- 图谱顶层只显示“科学与技术体系”“疾病与临床问题”“研究与证据”三个入口，避免把全量节点一次性铺开；
- 学科与疾病分组使用独立导航数据，不把目录节点冒充医学实体；
- 主题子图限定为焦点节点周围两跳、最多 40 个节点，证据链单独展开；
- 41 个现有实体均有且仅有一个主导航归属；交叉学科关系保留独立字段，后续可按证据补充；
- 已批准但尚未完成内容审核的新科学门类只显示为规划项，不生成空白实体页；
- 首页右上角加入原创 SVG 徽标，页眉左上角品牌标志和站点 favicon 同步采用其紧凑版本；扳手、锤子和试管从三个方向连接医疗十字，并提供可访问性标题和说明；
- 徽标在桌面、平板和移动宽度下分别采用纵向、横向和单列布局。

## 浏览器验证

- 桌面宽度：首页、三栏图谱探索、实体页和证据页均可显示；
- 移动宽度：导航、首页标题、筛选区和图谱画布可响应式排列；
- 连续中文问题“中风以后机器人训练手臂”可归纳到脑卒中、机器人学、康复机器人等候选；
- 首页示范主题数量固定为 6；
- 点击图谱节点或关系可更新详情侧栏；
- 实体页可先阅读通俗简介和可靠来源，再沿关系进入关联详情页；
- 阅读身份与研究兴趣可保存在浏览器本地；
- “与我相关”视图可读取本地研究兴趣。
- 本地开发服务器首页与图谱探索页均返回 HTTP 200；首页输出包含徽标及其可访问性说明。

## 本轮修复

- 修正了使用广义标签筛选时首页出现第七张主题卡的问题，改用明确的六主题 ID 清单；
- 为连续中文输入增加概念片段匹配，避免只有空格分词时才能识别技术方向；
- 修正 Cytoscape.js 样式属性的严格 TypeScript 类型；
- 将全量图谱改为逐层下钻，并修正中心节点和主题焦点的布尔选择器；
- 校正数据 Schema 中既有资料类型与实际数据之间的命名漂移；
- 在沙箱检查中通过进程环境变量关闭 Astro 遥测，未写入用户系统配置目录。

## 尚未完成

- 首批证据和新增样板证据尚未通过逐条医学审核；
- 41 个实体页已接入通俗简介，简介来源已结构化登记，但仍待逐条医学和事实审核；
- 实体页的关联内容先显示五种卡片类型选择项，用户选择后才展开对应相关推荐；
- 未来研究方向条目已创建 4 条，但尚未通过逐条审核；
- 分层导航已经限制单次展示规模，但大型节点库仍需要后端检索、按需加载和导航分组维护工具；
- 最终视觉风格、站点名称和公开部署平台尚未确定。

## 发布结论

该版本可作为内部功能原型继续评审，不建议在医学内容审核前作为正式公共知识库发布。
