# 医学 × 先进技术

> 技术的终极目的，就是解决人类疾苦。

这是一个面向科研人员、同时兼顾公众理解的中文医学技术知识导航站。项目从疾病和临床问题出发，追踪不同科学与技术路径正在解决什么、已经证明什么，以及距离真实患者获益还有多远。

本站用于科研信息检索和知识导航，不提供诊断、治疗建议或专业医学决策。

## 页面与交互

- 首页提供自然语言检索和可选阅读偏好，使用本地规则进行候选匹配，不进行疾病诊断；
- 首页不再固定展示有限数量的医学主题，内容统一通过搜索和图谱进入；
- 首页云图以“医学×先进技术”为中心，采用稳定、可重复的关系优先布局；
- 云图支持拖动节点、空白处自由平移、触控板双指滑动平移、双指捏合缩放，以及独立的加、减和适应按钮；
- 点击或拖动节点时直接相关连线保持高亮并显示节点上下文卡片；再次点击同一节点进入详情页；点击连线时高亮该线并显示关系摘要；高亮色与每条连线的箭头发出节点颜色一致，点击空白处取消高亮；
- 核心能力使用深绿，技术使用钴蓝，避免视觉混淆；
- 完整图谱页采用按层级和类型分区的格子视图，详情按需展开，不再绘制拥挤的全量放射状连线；
- 198 个实体页均默认展示分段、通俗的“医学连接”解释；专业说明只保留术语、机制、证据阶段、专业限制和研究问题等新增信息，没有新增信息时不显示入口；来源拆分为“科普解释依据”和“研究与专业依据”；
- 实体页默认展示全部关联并按证据量和研究阶段排序；内容类型筛选默认收起，关联卡片在桌面、中等宽度和手机上分别采用三列、两列和单列布局，并提供吸顶页内导航、读者角色阅读起点、折叠式专业来源和移动端关系列表；
- 实体、关系、证据和未来方向页面均提供来源、限制、研究阶段和继续阅读入口。

## R1 来源核验规则

项目采用 R1“来源核验型知识库”规则。本项目不具备独立医学专家审校能力，专家审校不属于发布关卡、阶段目标或未来待办。`expert_review_status: not-performed` 仅用于透明披露，不表示存在待完成的专家审校任务。

当前 132 张公开证据卡均为：

- `review_status: source-checked`；
- `expert_review_status: not-performed`；
- `publication_status: public`；
- 机器辅助整理，并明确披露未经独立医学专家审核。

公开内容必须经过逐条来源核对、事实边界检查、自动数据验证和产品构建验证。监管批准、临床试验、早期人体研究、动物/体外研究及理论研究必须明确区分；阴性结果、安全性、利益冲突和外推限制不得省略。

## 技术结构

- Astro：生成首页、实体页、关系页、证据页和方法页等静态内容；
- React：承载自然语言归纳、阅读偏好、首页云图和完整图谱格子浏览；
- Cytoscape.js：绘制首页及局部关系图；
- TypeScript：约束组件和知识图谱数据字段；
- JSON + Markdown：结构化保存图谱数据、通俗医学连接和两类来源映射，Markdown 保留可追溯的专业底稿与证据原稿；实体页会从专业底稿中排除与大众解释职责相同或文字高度重合的章节；
- Cloudflare Pages Functions + D1：保留用户内容需求收集接口代码，但当前阶段明确暂缓配置、接通和部署。

项目当前保持静态优先，不使用图数据库，也不依赖付费 AI 服务。

## 验证

```bash
npm run validate:data
npm run audit:coverage
npm run audit:professional
npm run check
npm run build
```

- `validate:data` 检查 JSON Schema、跨文件引用、Markdown 文件、导航归属、阻断来源和公开证据规则；
- `audit:coverage` 报告门类缺口、完整路径、重复关系和越层关系；
- `audit:professional` 检查专业说明是否重新显示通俗简介、医学连接等重复职责章节，并执行文字重合度门槛审计；
- `check` 执行 Astro 与 TypeScript 检查；
- `build` 生成完整静态站点至 `dist/`。

当前验证基线：198 个节点、198 条通俗医学连接、242 条关系、132 张证据卡、194 条来源和 4 条未来方向通过数据校验；16/16 个批准门类落地，覆盖提醒为 0；专业层保留 119 个具有新增信息的入口、隐藏 79 个无新增信息的入口，共展示 234 个专业章节并省略 549 个重复或高重合章节；TypeScript 检查通过；构建生成 582 个静态页面。当前 Windows 开发机运行 `astro check` 会触发既有的 Node 堆内存问题，详见 `HANDOFF.md`。
